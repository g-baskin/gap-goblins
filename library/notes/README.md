# library/notes/

**This folder is for human notes only.**

## The agent WILL NOT write here

The `library-guardian` agent is explicitly instructed to never create, edit, rename, or delete any file in this folder. If it has something worth capturing, it will write to `library/knowledge-base/` instead.

This is your scratch space. Use it for:

- Research snippets you don't want to lose.
- Rough thoughts before they become proper docs.
- Links, quotes, meeting notes, design explorations.
- Anything transient that doesn't yet deserve a place in the knowledge base.

## Conventions (optional)

None enforced. If you like structure:

- Prefix with a date: `2026-05-15-<topic>.md`.
- Or use subfolders by topic.

Do whatever helps you — the agent won't touch it either way.
